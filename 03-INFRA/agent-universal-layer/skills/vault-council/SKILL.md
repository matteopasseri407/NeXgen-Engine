# Renamed to `nexgen-council`

This command acts on the engine and its tooling, not on the Vault. The
`vault-` prefix said the opposite, so the skill is now `nexgen-council`. Memory
commands keep the `vault-` name, because the memory is the Vault.

Do not follow a runbook from here, there is deliberately only one copy so the
two names cannot drift apart:

1. Load the `nexgen-council` skill and follow it exactly.
2. Mention once, in passing, that the command is now `nexgen-council`. Do not make a
   lesson of it and do not stop to ask.
